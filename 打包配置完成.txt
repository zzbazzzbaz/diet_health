【推荐使用方式：GitHub Actions】

优势：
✨ 自动在 Windows、macOS、Linux 三个平台打包
✨ 完全免费（公开仓库）
✨ 并行构建，速度快
✨ 无需本地环境配置

使用步骤：
1. 推送代码到 GitHub
   git push origin main

2. 访问 Actions 页面查看构建进度

3. 下载打包文件（Artifacts 部分）


【本地打包方式】

如果不想使用 GitHub：
- macOS: ./build.sh
- Windows: build.bat

⚠️ 限制：只能打包当前系统的版本
